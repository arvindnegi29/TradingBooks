## Chapter5: options (PDF78–86)
- Separate intrinsic value from extrinsic value; cheap OTM premium does not imply cheap valuation. Expiration breakeven depends on strike plus/minus premium and costs; a directionally correct move can still lose premium. Book uses US equity multiplier100, not a universal options multiplier.
- Carter's directional preference is ITM call delta around +0.70 or higher, corresponding negative put delta with absolute magnitude around0.70; PDF81 accepts call0.69 as close enough. This is an author preference, not a universal optimal strike or mandatory plugin threshold.
- Example hourly squeeze for1–3-day swing: compression dots release, histogram abovezero suggests long/belowzero short; exit when momentum weakens and manage underlying-based invalidation (PDF82–83). Actual squeeze formula lies later in book; no implementation claim here. Example uses underlyingGS stop2dollars and approximate premium change1.40 atdelta0.70. Delta approximation must not become guaranteed executable premium stop/target: gamma,IV,theta,spread matter.
- IV crush and event risk can outweigh correct direction (PDF83–85). Author prefers buying quiet-IV directional plays and considers selling heightened-IV premium. HighIV itself is not a short-option edge or automatic sell. Needs relative valuation, event move/risk, actual bid/ask/Greeks and user risk.
- Historical GS gap-down put-selling illustration: scan about30minutes before US cashopen, sell firstOTM put shortly afteropen, close same day on IV normalization; nominal1:1 risk/reward. Naked risk explicitly acknowledged. Do not adopt naked selling or assume stops cap gaps. A defined-risk same-expiry vertical requires both fills, prices and payoff.
- PDF85 example bullish call spread buy155at7.30/sell160at3.80 => debit3.50, width5, expiry maxgain1.50/maxloss3.50 per share beforecosts. No guaranteed sideways profit; nettheta can have either sign depending underlying/tenor.
- Author later describes longITM monthly and shortOTM weekly as a vertical; these have different expiries and are diagonal structure, with assignment, calendar and residual-leg exposure. Do not package as ordinary fixed-risk same-expiry vertical.
- PDF86 futures option premium=quotedpoints×contractmultiplier. Futures margin is not equivalent economic purchase price or capped downside; text conflates ability to enter futures with buying option at comparable capital.

On strong days buyTICKpullbacktozero rather thanfade+1000; holdshort whilezeroralliesreject, exitopposing+600 in later update (PDF92). This conditional exception is essential; never blindly fade everyextreme.
